# Research & Knowledge Assistant

An AI-powered document intelligence system built using LangChain and Retrieval-Augmented Generation (RAG).

The application will ingest documents, retrieve relevant information, and generate evidence-grounded answers with source citations.

## Planned Technology Stack

- Python
- LangChain
- Groq
- Sentence Transformers
- ChromaDB
- FastAPI
- Pydantic

## Project Status

Under development.

## Learning Objectives

- Document ingestion and processing
- Embeddings and vector databases
- Retrieval engineering
- RAG pipelines using LangChain
- Grounded generation and citations
- Evaluation and deployment
